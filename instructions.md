# STYX Instructions

## Overview
STYX (Systematic Trader's Yield eXtractor) is a research and paper-trading pipeline for Indian equities.

## Setup
1. Clone the repository
2. Install dependencies: `pip install -r requirements.txt`
3. Configure API keys for data sources

## Usage
- Research mode: `python run_research.py`
- Paper trading: `python run_paper_trading.py`

## Contributing
- Follow the coding standards in CODE_OF_CONDUCT.md
- Submit pull requests for review
- Ensure all tests pass before merging

## Configuration
- Edit `.env` file for environment variables
- Update `config.yaml` for strategy parameters
