# Use a one-time Gate 0 capital exception

Route B normally uses Surya-approved planning capital, but the single Gate 0 isolation test uses the explicitly approved ₹2,000 at 1× so the safety exercise does not rely on the ₹1 Cr default or planning capital. This exception applies only to the specified virtual MIS order, is recorded in `evidence/gate_0.json`, cannot be used as strategy evidence, and requires a reset to approved planning capital before Gate 3 or any research or strategy run.
